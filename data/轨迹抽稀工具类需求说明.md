需求：
1. 轨迹线绘制：使用L.polyline绘制轨迹线，轨迹线使用 Douglas-Peucker 简化，要支持设置颜色、宽度、透明度等参数;默认蓝色、dash线样式
2. 轨迹点绘制：使用L.circleMarker绘制轨迹点，要支持设置大小、颜色、边框等参数;默认黄色、边框白色
3. 特殊轨迹点：判断eventData数组是否为空，不为空则绘制特殊轨迹点，特殊点位不能被抽稀掉，而且要更高层级展示；特殊轨迹点用红色点、边框白色
4. 抽稀规则： 
    -- 按照网格抽稀，网格大小要根据当前地图缩放级别来确定；
    -- 缩放层级对应的网格大小也要可以支持配置，默认先给一套比较合适的配置；
    -- 不需要每一级都做一套网格大小配置，可以1-3、3-5等，最高18级；
    -- 每次地图缩放到对应的级别范围抽稀之后，要把当前抽稀数据保存起来，下次再进入这个级别范围时，从保存的数据中抽稀，这样能避免每次都重新抽稀数据
    -- 缓存结果要在清除轨迹时清除
5. 点击事件回调：点击某个marker，触发回调，返回点击的marker的经纬度、eventData等数据
6. 多轨迹绘制： 可能需要同时绘制多条轨迹，所以要对每条轨迹都缓存对应的抽稀结果，并且支持删除某个轨迹和全部轨迹
7. 当轨迹点数量超过一定阈值（如 5000 个点）时，使用 Leaflet 的 Canvas 渲染器替代默认的 SVG 渲染器
Canvas 对大量点的渲染性能远超 SVG（数量级差异）

需求：
1. 这个插件还会接收一份这样格式的数据，其中eventData字段不在是数组结构，而是一个对象结构，对象格式为
{
    "eventType": 1,
    "eventId": "2000794289127546882"
}
后端返回的格式可以保证eventId相同的数据会挨在一起，这样前端就可以根据eventId来判断是否是同一个异常数据，对同一个异常数据要绘制一段加粗的带透明度红线
2. 异常数据绘制是需要通过开关控制是否打开的，也就是在addTrack方法中options中添加一个参数，控制是否绘制异常数据，只有绘制异常数据时eventData才会是对象结构或者null，否则是数组结构
3. addTrack方法中options中还需要添加一个参数缩放级别，地图缩放等级要大于等于这个级别才会去绘制异常线段，否则还是按照第一部分的规则去绘制，默认15级
4. 如果大于这个缩放级别之后，开始监听地图可视范围内的点位，获取到点位后要查看每一个点位的eventData字段，字段中将eventId相同的数据以及经纬度都取出来分组，只有一个eventId不绘制，会得到多个异常id对应的线段，然后将这些线段绘制到地图上，下一次绘制时，要清除掉上一次绘制的异常线段，重新绘制新的异常线段
5. 异常线段绘制只有在开关打开时才绘制，否则效果是和第一部分的绘制效果一样的，所以要做好轨迹数据兼容，区别就是eventData字段，在第一部分中传入的是数组或者空数组，在第二部分中传入的是对象或者null
